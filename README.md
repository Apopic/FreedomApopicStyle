# FreedomApopicStyle

自己流の太鼓シミュレーターです。TJA 譜面 (太鼓さん次郎の形式) と osu!taiko 譜面で遊べます。
オンライン対戦・段位道場・トレーニング・譜面制作・演奏の録画にも対応しています。

## 動作環境

| | 必要 | 推奨 |
| --- | --- | --- |
| OS | Windows 10 (64bit, バージョン 1803 以降) | Windows 11 / Windows 10 (64bit, バージョン 2004 以降) |
| CPU | 2 コア 4 スレッド | 4 コア 8 スレッド以上 |
| メモリ | 4GB | 8GB 以上 |
| GPU | DirectX 12 に対応したもの (機能レベル 11_0 以上。2013 年ごろ以降の GPU・内蔵 GPU) | 録画もする時は NVIDIA / AMD / Intel のハードウェアエンコーダ (NVENC / AMF / Quick Sync) 対応のもの |
| ディスプレイ | 1280×720 以上・60Hz | 120Hz 以上 |
| サウンド | Windows で音が出るもの | 低遅延の共有モードに対応したもの (多くの USB オーディオ・最近のオンボードサウンド)。ヘッドホン・有線のスピーカー |
| ストレージ | 200MB + 曲のデータ | SSD |
| その他 | キーボード | 有線のキーボード・太鼓コントローラー |

- ワイヤレス (Bluetooth) のイヤホン・スピーカーは音が大きく遅れるため、演奏には向きません
- 録画は 4 スレッド以下の CPU では 30fps、ハードウェアエンコーダか 8 スレッド以上の CPU なら 120fps まで快適に録れます
- Android 版: Android 9 以降

## はじめに

1. `FreedomApopicStyle.exe` を起動します。初めての起動では、この PC に合わせたおすすめの設定 (画面・サウンド・録画) を自動で行います
2. 曲は `Songs` フォルダに入れます (1 曲 1 フォルダ。中に `.tja` と音源)。ほかの場所のフォルダは設定の「フォルダ」から追加できます
3. `Single` → 曲 → 難易度を選ぶと演奏が始まります

### 演奏のキー (初期設定)

| | 左 | 右 |
| --- | --- | --- |
| カッ (ふち) | `D` / `S` | `K` / `L` |
| ドン (面) | `F` / `G` | `J` / `H` |

設定の「キー」で変えられます (1 か所に最大 16 個)。メニューは `↑↓←→` で選び、`Enter` (またはドン) で決定、`Esc` で戻ります。

### 判定のずれを合わせる

「音に合わせて叩いているのに早い・遅いと判定される」時は、設定の「判定」にある **オフセット自動調整** を使ってください。
クリック音に合わせて叩くだけで、判定オフセット (`JudgeOffset`) をその人とその PC に合わせます。
手で合わせる時は、遅いと判定される時は `JudgeOffset` を大きく、早いと判定される時は小さくします。

## 演奏

- **ポーズ** (`PauseDisplay` を ON): 演奏中に `Tab` / `Esc` で一時停止し、「続ける」「最初から」「選曲へ戻る」を選べます (オンラインでは使えません)。
  OFF の時は `Esc` で選曲へ戻り、`Tab` で最初からやり直します
- **トレーニングモード** (`TrainingMode`): 止まっている間に `PageUp` / `PageDown` で小節を移動します。押し続けるとだんだん速くなります。
  `Home` / `End` で最初・最後へ、`↑↓` で譜面分岐の切り替え、ドン・`Space`・`Enter` で再開します
- **スコアメーター** (`ScoreMeter`): 演奏中とリザルトに判定のずれを表示します。中央がぴったり・右が遅い・左が早い。▲ が平均です
- **オートプレイ** (`AutoPlay`): 自動で演奏します

## 選曲画面

- `↑↓` で曲、`←→` で難易度を選びます。マウスでも操作できます (クリックで選択・選んでいる曲をもう一度クリックで決定・ホイールで移動)
- 各難易度にはベストスコアと、その時の良・可・不可・連打・最大コンボ・精度を表示します
- `F5`: お気に入りに登録 / 解除 (★)。ジャンルの箱ではその中の曲をまとめて登録します
- `F6`: お気に入りだけを表示
- `F7`: 選んでいる譜面を譜面制作モードで開く

### 絞り込み (`Space`)

| 項目 | 内容 |
| --- | --- |
| キーワード | タイトル・サブタイトル・ジャンルで探す (空白で区切ると全部を含むもの。`t:` タイトル / `s:` サブタイトル / `g:` ジャンル / `c:` コース / `lv:8` レベル / `fav` お気に入り) |
| 一致のしかた | 部分一致 / 完全一致 |
| ジャンル | ジャンルのフォルダ (`genre.ini`) で絞る |
| コース | かんたん～段位 |
| お気に入りのみ | ON / OFF |

「ランダム」で絞り込んだ中から 1 曲を選びます。

## 段位道場

モード選択の `Dan` で、決められた曲を続けて演奏し、合格条件 (精度・不可の数・連打数など) を目指します。
赤合格と金合格があり、課題曲と条件は段位を選ぶと表示されます。

## 設定

マウスかキーボード (`↑↓` 項目 / `←→` 変更 / `Enter` 決定 / `Tab` カテゴリ / `Esc` 戻る) で操作します。項目を選ぶと画面の下に説明が出ます。

### おすすめ設定 (`Recommended`)

この PC の画面・CPU・GPU・音声機器を調べて、表示・サウンド・録画の設定を決めます。変わる項目を確認してから適用します。
何度か演奏すると、それまでの判定のずれの平均から判定オフセットもおすすめします。
判定幅・演奏速度・譜面の速さ・音量・キーなど、好みで決めるものは変えません。

### 遅延を減らすには

- まず **おすすめ設定** と **オフセット自動調整** を使ってください
- `BufferSize` を小さくすると音の遅れが減ります (小さすぎると音がとぎれます)
- `Exclusive` (排他モード) を ON にすると、音の遅れをさらに減らせます。ただし演奏中はほかのアプリ (ボイスチャットなど) の音が出なくなります
- 120Hz 以上のディスプレイでは、画面の遅れも小さくなります。フルスクリーン (`FullScreen`) にするとさらに遅れが減ります
- デバッグ表示 (`ViewDebug`) で FPS と音声の出力 (WASAPI の排他・共有、バッファの長さ) を確かめられます

### 主な項目

- **ゲーム**: 名前 (`PlayerName`)・称号 (`TitleName`。名前の上に表示)・オートプレイ・ポーズ・トレーニングモード・スキン
- **フォルダ**: 譜面のフォルダの追加 (「参照して追加…」か「パスを入力して追加」) と削除。見つからないフォルダは赤く表示します
- **判定**: 判定幅・`JudgeOffset` (判定のずれ)・`SongOffset` (音源をずらす)・`ChartOffset` (音符をずらす)・スコアメーター・オフセット自動調整・次郎形式
- **画面と音**: おすすめ設定・垂直同期・フルスクリーン・音量・サウンドの出力
- **オンライン**: 接続先 (`ServerAddress` / `ServerPort`)・Discord のステータス表示
- **録画とツール**: 録画の設定・ffmpeg / yt-dlp の導入と更新
- **キー**: 演奏のキーの割り当て (枠の「+」で追加、`Delete` か右クリックで外す)

設定は `config.json` に保存されます。

## 録画

設定の `RecordPlay` を ON にすると、演奏を録画して `recordings` フォルダに保存します。

- リザルトで「録画を保存しますか?」と聞きます (`Y` で保存 / `N` で破棄)
- 形式: MP4 / MKV / MOV / WebM / GIF、音声だけの M4A / MP3 / WAV / FLAC
- フレームレート: 30 / 60 / 120fps。エンコーダ (`RecordCodec`) は、GPU のハードウェアエンコーダ (`h264_nvenc` / `h264_amf` / `h264_qsv`) を使うと演奏中の負担が減ります
- 録画には **ffmpeg** が必要です。無い時は導入するか聞きます (下の「外部ツール」)
- 画面右上の REC 表示などは録画には映りません

## オンライン

モード選択の `Multi` で、最大 4 人で同じ曲を演奏できます。他の人が同じ曲を持っている必要はありません (ホストの曲を受け取って遊べます。受け取った曲は保存されません)。

- **サーバーに接続**: 設定の接続先に接続します
- **接続先を入力して接続**: `192.168.0.2:8080` のように入力します
- **この PC でサーバーを起動してホストになる**: ゲームと同じフォルダの `FreedomApopicStyleServer.exe` を起動して接続します

待機室には招待用の接続先が表示されます (`C` でコピー)。最初に入った人がホストになり、全員の準備ができるとホストが開始できます。通信は暗号化されています。

### サーバー (`FreedomApopicStyleServer.exe`)

ポートを決めて「開始」すると、ほかの人が参加できる接続先 (外部 / LAN / この PC) が表示されます。選んで「コピー」で伝えてください。

- **インターネット越しに遊ぶ時**: ルーターの UPnP が有効なら、ポートは自動で開きます。使えない時はルーターで TCP のポート (初期設定 8080) を開放し、
  「外部アドレス」にグローバル IP を入れて開始してください
- 回線によっては (プロバイダ側の NAT がある CGNAT など) インターネットからは参加できません。同じ LAN からは参加できます

## Discord

PC 版の Discord を起動していると、プロフィールに選曲中・演奏中の曲などを表示します (設定の `DiscordRPC` で ON / OFF)。
オンラインのルームにいる間は、フレンドに「参加」ボタンが表示されます。「参加をリクエスト」された時は待機室で `Y` (許可) / `N` (断る) を押します。
表示されない時は、Discord の「アクティビティのプライバシー」でアクティビティの共有を ON にしてください。

## 譜面制作モード

モード選択の `Edit` (または選曲画面で `F7`) で、TJA 譜面を作ったり直したりできます。

| 操作 | 内容 |
| --- | --- |
| 左クリック | 選んでいる音符を置く (もう一度で消す) |
| 右クリック | 音符を消す / 命令のラベルを消す |
| 命令のラベルをクリック | 命令を編集 |
| ホイール | スクロール |
| `0`～`9` | 音符の種類 (1 ドン / 2 カッ / 3 大ドン / 4 大カッ / 5 連打 / 6 大連打 / 7 風船 / 8 連打終点 / 9 くすだま / 0 休符) |
| `↑↓←→` / `Enter` / `Delete` | カーソルの移動 / 置く / 消す |
| `Shift+クリック` / `Shift+矢印` | 範囲を選ぶ |
| `Ctrl+C` / `Ctrl+X` / `Ctrl+V` | コピー / 切り取り / 貼り付け |
| `Ctrl+S` / `Ctrl+Z` / `Ctrl+Y` | 保存 / 元に戻す / やり直し |
| `F5` | テストプレイ (カーソルの小節から) |
| `Space` | 試しに流す / 止める |
| `Esc` | 閉じる |

- 上のボタンにマウスを乗せると説明が出ます
- **折りたたみ**: 範囲を選んで「折りたたむ」と 1 行にまとめます。折りたたんだ範囲は譜面・コースごとに記憶し、次に開いた時も折りたたんだままにします
- **「縮めても間隔を保つ」**: ON にすると、`#MEASURE` で小節を縮めても音符の間隔を保ちます (はみ出した音符は消えます。初期は OFF)
- **グリッド**: 1～256 分割。「○ 分割…」の一覧で、よく使う分割に ★ を付けると ◀ ▶ で切り替えられます
- **ヘッダー**: タイトル・BPM・音源 (`WAVE`)・背景動画などを編集します。`SONGLINK` / `MOVIELINK` は「取得」で URL から音源・動画をダウンロードします
- **命令**: よく使う命令 (BPM 変化・スクロール・拍子・ゴーゴー・分岐など) を入れます
- **ギミック**: 太鼓さん次郎の定番のギミック (慣性移動の減速・加速・逆走・停止・瞬間移動・点滅、選んだ範囲のコマ送りなど) を、数値を入れるだけで作ります
- **次郎ずれ補正**: 太鼓さん次郎では BPM の小数以下が `#BPMCHANGE` ごとに切り捨てられ、譜面が少しずつ早くなります。その分を小節の頭の `#DELAY` で打ち消します (範囲を選んでいればその範囲、無ければコース全体)
- **自動推定**: 音源から BPM・開始位置 (`OFFSET`)・拍子を推定します (推定なので、テストプレイで確かめてください)
- **テストプレイ**: 保存していなくても演奏できます。`F1` でオートプレイの切り替え。記録は残りません
- **保存**: 元の文字コードのまま保存し、初めて上書きする時は元のファイルを `.bak` として残します

## 外部ツール (ffmpeg / yt-dlp)

録画と音源の変換には ffmpeg、`SONGLINK` / `MOVIELINK` のダウンロードには yt-dlp を使います。ゲームには入っていません。
必要になった時か、設定の「ツール」から、確認のうえ公式の配布場所からダウンロードしてゲームのフォルダに置きます (ダウンロードしたファイルは公式の値と照合します)。

| ツール | 配布元 | ライセンス |
| --- | --- | --- |
| yt-dlp | github.com/yt-dlp/yt-dlp | Unlicense |
| ffmpeg | BtbN/FFmpeg-Builds (FFmpeg 公式サイトが案内している Windows 版) | GPL v3 |

ダウンロードする動画・音源の利用は、各サイトの規約と著作権に従ってください。

## Android 版

- Android 9 以降で動きます。画面のタッチ太鼓で演奏します
- 選曲は上下スワイプで移動、タップで選択、もう一度タップで決定します
- 曲の zip をファイル管理アプリで開く (共有する) と、`Documents/FAS/Songs` に入ります
- 録画・Discord・サーバーの起動は PC 版だけの機能です

## 困った時は

| 症状 | 対処 |
| --- | --- |
| 判定がずれる | 設定の「オフセット自動調整」を使う。ワイヤレスのイヤホンは使わない |
| 音がとぎれる・ノイズが出る | `BufferSize` を大きくする。`Exclusive` を OFF にする |
| 画面がカクつく | おすすめ設定を使う。`WaitVSync` (垂直同期) を ON にする |
| 録画がカクつく・コマ落ちする | `RecordCodec` を GPU のエンコーダにする。`RecordFps` を下げる |
| 起動しない・画面が出ない | GPU のドライバを更新する (DirectX 12 対応の GPU が必要です) |
| オンラインでつながらない | サーバーのポートが開いているか、接続先とポートが合っているかを確かめる |

## 譜面・スキンを作る人向け

### 段位譜面

```
TITLE:段位名
COURSE:Dan
EXAM1:g,95,98,m        // 全体条件: 種類,赤合格,金合格,範囲 (m=以上 / l=未満)
EXAM2:jb,20,10,l
#START
#NEXTSONG 曲名,サブタイトル,ジャンル,音源ファイル,SCOREINIT,SCOREDIFF,レベル,コース
EXAM3:c,100,150,m      // #NEXTSONG の後に書いた条件はその曲だけの条件
(譜面)
#NEXTSONG ...
(譜面)
#END
```

条件の種類: `g` 精度 / `jp` 良 / `jg` 可 / `jb` 不可 / `s` スコア / `r` 連打 / `h` 叩けた数 / `c` 最大コンボ

### 次郎形式 (`JiroChartMode`)

ON にすると、太鼓さん次郎と同じ時刻の計算 (整数ミリ秒)・判定の順番 (ダミーノーツ)・音符の表示位置・分岐のタイミングで演奏します。
次郎向けに作られたギミック譜面は ON にすると作者の意図どおりに見えます。`#HBSCROLL` / `#BMSCROLL` を含む譜面を開いた時は、その演奏だけ ON にするか聞きます。

### ギミックの命令

- `#HBSCROLL`: 太鼓さん次郎と同じく、BPM 変化を書かれた順に並べて位置を決めます。負の BPM・負の `#MEASURE` を使った逆走・瞬間移動・点滅なども次郎と同じに見えます
- `#BMSCROLL`: `#HBSCROLL` と同じで、`#SCROLL` を無視します
- 譜面分岐: 分岐する小節の 1 つ前の小節の頭で決まります。精度 `p`・連打数 `r` は直前の `#SECTION` から、スコア `s` は曲の最初からの値で判定します

### 背景動画

`BGMOVIE:` に動画ファイル、`MOVIEOFFSET:` に開始のずれ (秒) を指定します。動画は演奏に合わせて再生され、一時停止や再生速度の変更にも合わせます
(背景動画の再生には ffmpeg が必要です)。

### スキン

スキンは `Skins` フォルダに入れ、設定の「ゲーム」で選びます。素材の場所・位置は各スキンの `skinconfig.json` で決めます。

- 演奏キャラ (`Playing.Image.PlayerChar`): `Div` で区切ったコマを使い、`Playing.Config` の `PlayerCharFrames` / `PlayerCharGoGoFrames` / `PlayerCharClearFrames` /
  `PlayerCharMissFrames` / `PlayerCharJumpFrames` で状態ごとのコマの順番を決めます
- コンボボイス (`Playing.SE.ComboVoice`): `[{ "Combo": 50, "FilePath": "Sound/Voice/Combo_50.wav" }]` の形で登録します。`FullComboVoice` はフルコンボの時の音です
- 大音符の効果音: `Playing.SE.DonBig` / `KaBig`
- ポーズ画面: `Playing.Image` の `PauseShade` / `PausePanel` / `PauseResume` / `PauseRestart` / `PauseExit` / `PauseCursor` (譜面制作のテストプレイでは `PauseTestResume` / `PauseTestRestart` / `PauseTestExit`)。
  書かなければ `Default` スキンの画像を使います
- 称号の位置: `Playing` / `Result` の `Font.TitleName` と `Config.TitleNamePos`
