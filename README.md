# FreedomApopicStyle
自己流太鼓シミュレーター

## オンラインプレイ

### サーバー (MultiServer)

`MultiServer/` がオンラインプレイ用のサーバーです (ソリューションに含まれています)。ウィンドウで操作します。

- ポート・「UPnP で自動ポート開放」・外部アドレスを決めて「開始」。接続先 (`アドレス:ポート`)・プレイヤー・ログが表示されます
- 接続先は選んで「コピー」(またはダブルクリック) でクリップボードへコピーできます (外部 / LAN / この PC)
- 設定は `MultiServer.ini` に保存されます
- 1 ルーム最大 4 人。最初に参加した人がホストになり、ホストが退出すると次の人に移ります
- 全員の読み込みが終わるとホストが開始でき、往復遅延を補正して同時に演奏が始まります

コマンドライン: `MultiServer.exe [ポート番号] [--public <IPv4>] [--no-upnp] [--autostart] [--minimized] [--parent <プロセスID>]`

| オプション | 内容 |
| --- | --- |
| `--public` | 外部 (インターネット) から参加してもらう時のアドレス (接続先の一覧に出す) |
| `--no-upnp` | UPnP でルーターのポートを開けない |
| `--autostart` / `--minimized` | 起動と同時に開始する / 最小化して起動する |
| `--parent` | 指定したプロセスが終了し、ルームが空になったら自動で終了する |

### インターネット越しに遊ぶ (ポート開放)

サーバーは開始時に、ルーターのポートを **UPnP で自動的に開け**、ルーターから外部アドレスを取得して接続先の一覧に出します。
ルーターの UPnP が有効なら、手動のポート開放は不要です (停止時にポートを閉じます)。

- UPnP が使えない時は、ルーターで TCP のポート (既定 8080) を手動で開放し、「外部アドレス」にグローバル IP を入れて開始してください
- プロバイダ側にもう 1 段 NAT がある回線 (CGNAT) では、インターネットからは参加できません (ログに表示されます)。同じ LAN からは参加できます
- Discord の Social SDK にはゲームのデータを中継する機能が無いため、ポート開放 (UPnP を含む) の代わりにはなりません

### 参加方法

ゲームの `Multi` を選ぶと参加方法を選べます。

- **サーバーに接続**: 設定の `ServerAddress` / `ServerPort` へ接続します
- **接続先 (アドレス:ポート) を入力して接続**: `192.168.0.2:8080` のように入力して接続します (ポートを省くと設定のポート。IPv6 は `[アドレス]:ポート`)。
  入力した接続先は `ServerAddress` / `ServerPort` に保存されます
- **この PC でサーバーを起動してホストになる** (Windows): `MultiServer.exe` (ゲームと同じフォルダ、またはビルド出力の `MultiServer` フォルダ) を
  `--autostart --minimized --parent` 付きで起動して接続します。既に同じポートで動いていればそのまま参加します

待機室には招待用の接続先 (`アドレス:ポート`) が表示されます (`C`: コピー / `V`: 外部・LAN などの切り替え)。
称号は名前と一緒に送られ、待機室・演奏画面・リザルトで他のプレイヤーにも表示されます。

### 通信と曲データ

- 通信はすべて暗号化されます (X25519 の鍵交換 + ChaCha20-Poly1305。メッセージの種類・名前・スコアも含む)。改ざんされたデータは破棄して切断します
- ホストが選んだ譜面と音源は 256KB ずつの暗号化ストリームで配布され、受信側はメモリ上だけで扱い、ディスクには書き込みません。
  他の人が同じ曲を持っている必要はありません
- 通信プロトコルは `Library/Net.hpp` (暗号は `Library/NetCrypto.hpp`) にあり、ゲームとサーバーで共有しています。
  変更した場合は `fasnet::ProtocolVersion` を上げてください (バージョンが違うと接続を拒否します)

## Discord (ステータス表示・参加ボタン)

Discord のプロフィールに、メニュー・選曲中・演奏中の曲とコース・リザルト・オンラインの待機室などを表示します。
オンラインのルームにいる間はフレンドに「参加」ボタンが表示され、押すとその人のゲームがルームに参加します
(サーバーの `アドレス:ポート` を Discord 経由で渡します。設定の接続先は書き換えません。演奏中・満員の時は表示しません)。「参加をリクエスト」された時は待機室で `Y` (許可) / `N` (断る) を押します。

- プレイヤーの操作は設定の `DiscordRPC` (ON / OFF) だけです。PC 版の Discord が起動していれば数秒で表示されます
  (Discord の「アクティビティのプライバシー」で、アクティビティの共有を ON にしてください)
- Discord クライアントのローカル接続 (公式 SDK と同じプロトコル) を使うため、SDK のファイルは不要です
- 参加ボタンでゲームを起動できるよう、起動時に `HKEY_CURRENT_USER\Software\Classes\discord-<ID>` へ実行ファイルの場所を登録します
- インターネット越しのフレンドが参加するには、サーバーに外部の接続先が必要です (上記の「インターネット越しに遊ぶ」)

## 選曲画面

選曲画面と段位選択画面はマウスでも操作できます (左クリック: 箱を選択、選択中の箱をクリックで決定 / ホイール: 一覧の移動・難易度の変更)。段位のボックスも斜めに並び、移動が止まってから開いて課題曲と合格条件を表示します。

選曲画面のボックスは緩い斜めに並びます。選択中の曲のボックスは少し開き、サブタイトルと COURSE・LEVEL の一覧を表示します (譜面がないコースは `--`)。
上下の一覧は先頭と末尾がつながるループ表示です。ボックス間は滑らかに移動し、移動が完全に止まって約 0.45 秒後に選択中の箱が開き始めます。

難易度選択への移動と選曲一覧に戻るときは、背景を暗くせず、ボックスと文字の透明度でフェードします。各難易度にはベストスコアと、その演奏の良・可・不可・連打・最大コンボ・精度を約 3 秒ごとにフェードで交互表示します。過去の記録などで判定結果が保存されていない項目は `-` で表示します。

### 絞り込み

`Space` (Android は検索ボタン) で絞り込み画面が開きます。項目はクリック、または `↑↓` で選んで `←→` で変更、`Enter` で入力・決定、`Esc` で閉じます。
該当する譜面の数と、選んでいる項目の説明がパネルの下に表示されます。

| 項目 | 内容 |
| --- | --- |
| キーワード | タイトル・サブタイトル・ジャンルに含む (空白区切りで全部を含む。`t:` `s:` `g:` `c:` `lv:8` `fav` も使えます) |
| 一致のしかた | 部分一致 / 完全一致 (タイトルかサブタイトルが一致。全角・半角、大文字・小文字は区別しない) |
| ジャンル | 譜面フォルダにあるジャンルフォルダ (`genre.ini`) から選択。中のジャンルフォルダの譜面も含む |
| コース | すべて / かんたん～段位 |
| お気に入りのみ | ON / OFF |

ボタンは「検索」「リセット」(条件をすべて解除)「ランダム」(絞り込んだ中からランダムに選ぶ)「閉じる」。該当がない条件では一覧を変えずに画面に残ります。

### お気に入り

- `F5`: 選択中の譜面をお気に入りに登録 / 解除 (一覧に ★ が付きます)。ジャンルの箱では中の譜面 (サブフォルダを含む) をまとめて登録 / 解除します
- `F6`: お気に入りのみ表示の切り替え
- お気に入りは `favorites.json` に保存されます (ゲームのフォルダ内の譜面は相対パスで記録)
- 通常譜面が 1 つもないジャンルは選曲画面に、段位譜面が 1 つもないジャンルは段位選択画面に表示されません

## 譜面制作モード

モード選択の `Edit` (または選曲画面で `F7`: 選んでいる譜面を開く) で、TJA 譜面を作ったり編集したりできます。

- **新しい譜面を作る…**: 保存先の `.tja` を決め、続けて音源を選びます (キャンセルで音源なし)。`WAVE:` は譜面からの相対パスで書きます
- **譜面を開く…**: 既存の `.tja` を開きます

編集画面:

| 操作 | 内容 |
| --- | --- |
| 左クリック | グリッドの位置に、選んでいる音符を置く (同じ音符の上ならもう一度で消す) |
| 右クリック | 音符を消す / 命令のラベルを右クリックで命令を削除 |
| 命令のラベルをクリック | 命令を編集 (空欄にすると削除) |
| ホイール | 小節のスクロール |
| `0`～`9` | 音符の種類 (1 ドン / 2 カッ / 3 大ドン / 4 大カッ / 5 連打 / 6 大連打 / 7 風船 / 8 連打終点 / 9 くすだま / 0 休符) |
| `↑↓` `←→` / `Enter` / `Delete` | カーソルの移動 / カーソルの位置に置く / 消す |
| `Shift+クリック` / `Shift+矢印` | 範囲を選ぶ (1 回目のクリックが始まり) |
| `Ctrl+C` / `Ctrl+X` / `Ctrl+V` | 選んだ範囲の音符・命令をコピー / 切り取り / カーソルの位置に貼り付け (小節をまたいでもよい) |
| `Ctrl+S` / `Ctrl+Z` / `Ctrl+Y` | 保存 / 元に戻す / やり直し |
| `F5` | テストプレイ (カーソルの小節から) |
| `Space` | 疑似再生 / 停止 (カーソルの位置から) |
| `Esc` | 閉じる (保存していない時はもう一度で閉じる) |

- 上のボタン: 保存・テストプレイ・ヘッダー・命令・ギミック・小節を挿入・小節を削除・元に戻す・やり直し・閉じる、コースの切り替え、グリッドの分割数、音符の種類
- **グリッド**: 1～256 分割。◀ ▶ は「よく使う分割」(★) だけを切り替えます。「○ 分割…」を押すと一覧が開き、左クリックでその分割に、右クリックで ★ の付け外し (`config.json` の `EditorGrids` に保存)
- **ギミック**: 太鼓さん次郎のギミック譜面の定番の書き方を、カーソルの小節の BPM・拍子から計算して挿入します (クリックして数値を入れる)。
  BPM変化 / 慣性移動 / 逆走 / DELAY停止 / 疑似停止 / 瞬間移動 (バグ式・120000式・BPM計算型) / 途中出現 / 痙攣 / 点滅 (逆走式・120000式) / DELAY± / 背面停止 / 背面逆走 / 連打背景 / ダミーノーツ (逆走式)。
  慣性移動は開始 BPM・開始拍子・段数・減速倍率を指定します。既定値 `400 1/8 4 1/2` では BPM を 400 → 200 → 100 → 50、拍子を 1/8 → 1/16 → 1/32 → 1/64 と変え、最後に元の BPM・拍子へ戻します。
  ギミックは `#HBSCROLL` が無いと次郎では動かないため、無ければコースに追加します。`JiroChartMode` を ON にすると次郎と同じ見え方になります
  (書き方は「太鼓さん次郎（無印）のギミック解説」(2reflexivity.blogspot.com) を参考にしています)
- **命令**: よく使う命令 (`#BPMCHANGE` `#SCROLL` `#MEASURE` `#DELAY` `#GOGOSTART` `#GOGOEND` `#BARLINEOFF/ON` `#SECTION` `#BRANCHSTART` `#N/E/M` `#BRANCHEND` `#LEVELHOLD`) か自由入力で、カーソルの位置に挿入します
- **ヘッダー**: `TITLE` `SUBTITLE` `BPM` `WAVE` (参照ボタンで音源を選べます) `SONGLINK` (「取得」で URL から音源をダウンロードして WAVE に保存。選曲画面の SONGLINK と同じく yt-dlp を使います) `BGMOVIE` `MOVIELINK` (「取得」で背景動画をダウンロードして BGMOVIE に保存) `OFFSET` `DEMOSTART` `GENRE` などと、コースの `COURSE` `LEVEL` `BALLOON` `SCOREINIT` `SCOREDIFF`。コースの追加・削除もここで行います
  `TITLE`・`SUBTITLE` の目のアイコンで、演奏画面での表示・非表示を切り替えます。非表示にすると値の先頭に `--` が付き、もう一度押すと外れます (元に戻す・やり直しにも対応)。
- **自動推定**: WAVE の音源を解析して、BPM・開始オフセット (`OFFSET`)・拍子を推定し、確認してから適用します。
  10ms ごとのスペクトルの変化から発音の強さを求め、その周期 (低音を重く見る) から BPM を、曲全体に拍の格子を当てはめて拍の位置を、
  低音の強い拍の周期から拍子 (3 拍子 / 4 拍子) を決めます。最初の小節の頭は最初に音が鳴った位置の拍です。
  3/4 拍子なら各コースの最初の小節に `#MEASURE 3/4` を入れます。推定なので、BPM が半分・倍になったり、曲の始まり方によってはずれることがあります (テストプレイで確かめてください)
- **疑似再生** (`Space` / 「▶ 再生」): 編集画面のまま、カーソルの位置から音源と一緒に流します。再生位置を緑の線で示し、
  音符を通り過ぎるとドン・カッの音を鳴らし、再生位置の小節が見えるように自動でスクロールします。置いた直後の音符もすぐに反映されます
  (`#BPMCHANGE` は途中でも効き、`#DELAY` は時刻を飛ばし、`#MEASURE` は小節の頭で効きます。`OFFSET` に合わせて音源の位置を決めます)
- 編集画面の文字は画面の高さに合わせた大きさで、ボタンは画面の幅に収まらなければ次の段に折り返します。ボタンにマウスを乗せると、画面下に説明が出ます
- 音符・連打の帯・レーンは、スキンの画像 (`Playing` の `Note` / `Lane`) で描きます (無いスキンでは色の丸で描きます)
- 疑似再生の速度は「速度」ボタンで 0.25～2 倍に変えられます
- **音源 (WAVE)**: 譜面からの相対パスで書きます。ゲームのフォルダの外にある音源を選んだ (または絶対パスを入力した) 時は、譜面のフォルダに複製します
- **テストプレイ**: 編集中の譜面 (保存していなくてもよい) で演奏します。途中の小節から始める時はトレーニングモードと同じく開始を待つので、ドンで始めます。`F1` でオートプレイと通常のプレイをその場で切り替えられます。記録は残りません。`Esc` で編集画面に戻ります
- **保存**: 元の文字コードのまま保存します (Shift_JIS の譜面は Shift_JIS。Shift_JIS で表せない文字がある時は UTF-8)。
  初めて上書きする時に元のファイルを `.bak` として残します。小節ごとの音符の細かさは元のまま書き、変えた小節だけが必要に応じて細かくなります
- 小節は書かれた順に並びます (分岐の #N/#E/#M の小節もそれぞれ表示)。音符の行の途中に書かれたコメント (`//`) は保存時に消えます

## 設定画面

マウス (クリック。ホイールは一覧のスクロール) とキーボード (`↑↓` 項目 / `←→` 変更 / `Enter` 決定 / `Tab` カテゴリ / `Esc` 戻る) で操作します。
項目名は `config.json` のキー名と同じです。

- **ゲーム**
  - `TitleName` (称号): 名札の名前の上に表示します (空欄なら表示しない)。スキンの `Playing` / `Result` に `Font.TitleName` と
    `Config.TitleNamePos` を書くとフォントと位置を変えられます (書かなければ名前のフォントの 3/4 の大きさで名前の上に置きます)
  - `Recommended` (おすすめ設定): 画面のリフレッシュレート・CPU のスレッド数・既定の音声デバイスを調べ、垂直同期・高速入力・描画タイミング・
    出力方式・サンプリングレート・バッファサイズ・判定オフセットを決めます。変更点を確認してから適用します。
    演奏オプション・判定幅・名前・キー・フォルダは変えません。初めての起動 (`config.json` が無い時) は自動で適用します
- **譜面フォルダ**: 最後の行の「参照して追加…」(エクスプローラーで選ぶ) か「パスを入力して追加」で追加し、各行の「削除」(または `Delete`) で削除します。
  ゲームのフォルダ内は相対パス、外は絶対パスで登録します。見つからないフォルダは赤く表示されます (変更は設定画面を閉じた時に読み込み直します)
- **判定**
  - `ChartOffset` (譜面オフセット): 音源はそのままで、音符・小節線の時刻だけをずらす (正で遅く)
  - `ScoreMeter`: 演奏中 (画面の中央・最下部) とリザルトに、その演奏の判定のずれを表示する。中央がぴったり・右が遅い・左が早い。
    色の帯は判定幅 (橙: 良 / 白: 可 / 青: 不可)、縦線は最近の打撃、▲ は平均、薄い帯はばらつき
  - `AutoOffset` (オフセット自動調整): 出力方式・バッファサイズ・デバイスの周期から音声の出力遅延の目安を求め、判定オフセットに設定する
- **オンライン**: `ServerAddress` / `ServerPort` / `DiscordRPC`
- **ツール** (Windows): `ffmpeg` / `yt-dlp` の導入・更新 (下の「外部ツール」)
- **キー**: 1 レーンに最大 16 個まで。末尾の「+」の枠で追加、`Delete` か右クリックで外します。割り当て待ちは `Esc` でキャンセルします。
  他のレーンと同じキーを割り当てると、他のレーンからは自動で外れます

### ポーズ画面 (PauseDisplay)

設定画面のゲームカテゴリで `PauseDisplay` を ON にすると、オフライン演奏中の TAB / Esc で譜面・音声を一時停止し、ポーズ画面を開きます (既定 OFF)。↑↓・Enter またはクリックで「続ける」「最初から」「選曲へ戻る」を選べます。TAB / Esc でも再開できます。ポーズ画面は約 0.18 秒でフェードインし、再開後 3 秒間は再びポーズできません。オンラインプレイでは無効です。録画中はポーズした区間を除いて再開します。

ポーズ項目の移動はカッ、決定はドンで知らせます。「最初から」は画面が完全に暗転してから譜面を読み直します。

UI は `Playing.Image` の `PauseShade`・`PausePanel`・`PauseResume`・`PauseRestart`・`PauseExit`・`PauseCursor` で管理します。既定画像は `Default/Image/Playing/PauseMenu/` にあり、各画像の `FilePath`・`Pos`・`Size` で差し替え・配置を変更できます。設定がない従来スキンは Default の画像を使います。

## 録画

設定 (表示) の `RecordPlay` を ON にすると、演奏を録画して `recordings/日時_曲名.<形式>` に保存します (演奏ごとに 1 ファイル)。

- **保存の確認**: リザルトに移ると「録画を保存しますか?」と聞きます (`Y` / クリックで保存、`N` で破棄)。答えずにリザルトを出た時と、途中で演奏をやめた時は保存します
- **形式** (`RecordFormat`): MP4 / MKV / MOV (H.264 + AAC。映像は再エンコードしない) / WebM (VP9 + Opus に変換) / GIF (音声なし・30fps・半分の大きさ) / 音声だけの M4A / MP3 / WAV / FLAC
- **フレームレート** (`RecordFps`): 30 / 60 / 120
- **音声** (`RecordAudio`): 「ゲームの音を録音」(録れなかった・無音だった時は譜面から作る) / 「譜面から作る」(曲の音源と、叩いた時の効果音を記録した時刻に合わせて混ぜる。WASAPI の排他モードでも音が入る)

- **ffmpeg が必要**です。無い時は `RecordPlay` を ON にした時に導入を提案します (下の「外部ツール」)。PATH にある ffmpeg も使えます
- 映像は DxLib の Direct3D 11 のバックバッファを GPU 上でコピーし、1 つ前にコピーしたものを読むので、描画は待たされません。
  決めたフレームレートの時だけコピーし、別スレッドで ffmpeg へ流して H.264 にします (`RecordCodec` 既定 `libx264` (`-preset veryfast`, 画質は `RecordCrf`)。
  NVIDIA / Intel / AMD の GPU エンコーダ `h264_nvenc` / `h264_qsv` / `h264_amf` も指定できます)。処理が追いつかずに捨てたフレームは保存時に表示します
- 音声は WASAPI のプロセスループバックで**このゲームの音だけ**を録ります (Windows 10 2004 以降。使えない時は PC 全体の音)。WASAPI の排他モードの時は録れないことがあります
- 画面右上の REC・書き出しのお知らせ・保存の確認は録画には映りません

## 外部ツール (ffmpeg / yt-dlp)

録画・音源の変換には ffmpeg、`SONGLINK` / `MOVIELINK` のダウンロードには yt-dlp を使います。**ゲームには同梱していません。**
必要になった時 (ダウンロードや録画を始める時) か、設定の「ツール」から、プレイヤーの同意を得て**配布元の公式な配布場所から**ダウンロードし、ゲームのフォルダに置きます。

| ツール | 配布元 | ライセンス |
| --- | --- | --- |
| yt-dlp | github.com/yt-dlp/yt-dlp の最新リリース (`yt-dlp.exe`) | Unlicense |
| ffmpeg | FFmpeg 公式サイトが案内している BtbN/FFmpeg-Builds の Windows 版 (`ffmpeg-master-latest-win64-gpl.zip`) | GPL v3 (ライセンス文を `licenses/ffmpeg-LICENSE.txt` に保存) |

- 配布するのはゲームではなく配布元で、プレイヤーが自分の PC に取得する形です。ゲームは別のプログラムとして起動するだけで、リンクはしません
- HTTPS (WinHTTP) でのみ取得し、配布元が公開している SHA-256 (`SHA2-256SUMS` / `checksums.sha256`) と照合します。一致しなければ置き換えません
- zip は Windows 標準の `tar.exe` (System32) で展開します。途中のファイルは `download/` に作り、終わったら消します
- ゲームのフォルダ → PATH の順に探します。yt-dlp には `--ffmpeg-location` でゲームの ffmpeg を渡します
- ダウンロードする動画・音源の利用は、各サイトの規約と著作権に従ってください

## ウィンドウ

ウィンドウモードでは、次の操作をしてもゲームの処理 (演奏・描画・入力・通信) が止まりません。

- タイトルバーのドラッグでの移動 (画面端へのスナップは無効)
- 閉じる・最小化・最大化ボタン (いつでも使えます。最大化すると画面をウィンドウに合わせて拡大。枠をつかんでのサイズ変更はできません)
  押して離した位置が同じボタンの上なら、どの通知 (ボタンを離した・マウスを動かした・キャプチャが外れた) で気付いても操作します
- タイトルバーとタスクバーにアプリのアイコン (`FASicon.ico`) を表示します
- システムメニューと Alt・F10 のメニューは開かないようにしています (タイトルバーの右クリック・アイコン・Alt+Space)

## 段位譜面

```
TITLE:段位名
COURSE:Dan
EXAM1:g,95,98,m        // 全体条件: 種類,赤合格,金合格,範囲 (m=以上 / l=未満)
```

条件の種類: `g` 精度 / `jp` 良 / `jg` 可 / `jb` 不可 / `s` スコア / `r` 連打 / `h` 叩けた数 / `c` 最大コンボ

## 次郎形式 (JiroChartMode)

設定の `JiroChartMode` を ON にすると (既定は OFF)、太鼓さん次郎 (taikojiro) と同じ扱いにします。

- **時刻**: 太鼓さん次郎の TJA 読み込みと同じく、整数ミリ秒で計算する (負になった時刻は 0)
  - 小節の頭 = 直前の `#BPMCHANGE` の時刻 + (その小節の残りの拍の長さを切り捨て) + (その後の小節の拍の長さの合計を切り捨て) + その後の `#DELAY`
  - 音符 = 小節の頭 (同じ小節に `#BPMCHANGE` があればその時刻) + (位置までの長さを切り捨て) + 小節の中の `#DELAY`
  - そのため小数のミリ秒は `#BPMCHANGE` のたびに切り捨てられ、判定が 0～2ms ずつ早くなる (例: BPM 220 の 4/4 は 1 小節 1090.9ms → 2 小節目の頭は 2180ms)
  - `#DELAY` はミリ秒に切り捨て (小数第 4 位以下は効かない)、止め始めは命令の位置の 1 区切り前 + 5ms
  - 命令の値は決まった文字数だけ読む (`#BPMCHANGE` `#SCROLL` は命令名の後 8 文字、`#MEASURE` `#DELAY` は 10 文字)。使えない BPM (0 など) は直前の BPM のまま
- **描画位置**: 音符の位置は 1px 単位で、BPM の区間ごとに px に直して切り捨ててから足す (`#BPMCHANGE` の瞬間に音符が少し戻って見えるのも次郎と同じ)
- **判定の順番 (ダミーノーツ)**: ドン・カッは分岐ごとに書かれた順に 1 つずつ判定する。今の音符が不可の幅を過ぎるか、
  次の音符が可の幅に入ったら見逃し (不可) にして次へ進む (1 フレームに 1 つ)。書かれた順より時刻が前の音符 (負の BPM などで作るダミーノーツ) は、
  前の音符が終わった時点で見逃しになり、叩けない。見逃した音符は消えずに流れていく
- **表示位置 (疑似停止など)**: 通常のスクロールでは、音符の位置 = (音符の時刻 - 現在時刻) × BPM × SCROLL で、BPM と SCROLL は
  **音符の時刻**でその時刻以前の最後の (書かれた順で後ろの) `#BPMCHANGE` / `#SCROLL` を使う (書いた位置の値ではない)
- **分岐**: 分岐中の `#BPMCHANGE` / `#MEASURE` / `#DELAY` は最初に書かれた分岐だけが有効で、全分岐の小節の時刻をそろえ、分岐の後は最初の分岐の終わりから続ける。
  次の分岐は判定の時刻 (1 つ前の小節の頭。連打数の分岐は分岐の頭) の 200ms 前から判定の時刻を過ぎるまで毎フレーム判定し直し、
  分岐が決まって分岐のアニメーションが始まった時から、決まった分岐の音符を判定する (前の区間の分岐の音符が残っている時は、それを判定し終えてから)。
  表示する音符の分岐は分岐の始まりの 50ms 前に切り替える。分岐の表示は決まった分岐へ 1 段ずつ 100ms で動く (普通→達人は玄人を通る)。
  次の分岐の区間の音符は、決まった分岐のものを先に表示する

## ギミック

- **通常スクロール**: 音符の位置 = (音符の時刻 - 現在時刻) × 音符の BPM × SCROLL
- **#HBSCROLL**: 太鼓さん次郎と同じく、`#BPMCHANGE` の区間を**書かれた順**に並べ、今の区間から音符の区間まで「区間の長さ × BPM」を足した距離 × SCROLL。
  時刻 t の区間は「時刻が t 以前の、書かれた順で最後の区間」です。負の BPM・負の `#MEASURE` で時刻が戻る譜面 (逆走・バグ式瞬間移動・痙攣・点滅・ダミーノーツなど) も次郎と同じに見えます。
  正の `#DELAY` の間は表示が止まり、これから来る `#DELAY` の分だけ後ろの音符が手前に寄ります
- **#BMSCROLL**: #HBSCROLL と同じで、#SCROLL を無視する (ハイスピード設定は有効)
- 次郎形式では、小節の途中に書いた `#MEASURE` は次の小節から効きます (次郎と同じ)。`#BPMCHANGE 0` は記述の誤りとして読み込みを止めます
- **譜面分岐**
  - 判定は分岐する小節の 1 つ前の小節の頭で確定する
  - 条件: 値 < 達人の条件 なら (値 < 玄人の条件 ? 普通 : 玄人)、それ以外は達人
  - 精度 `p` と連打数 `r` は最後の #SECTION からの値、スコア `s` は曲の最初からの値
  - 分岐ごとに #BPMCHANGE / #MEASURE / #DELAY で時刻を計算し、分岐の後は最後に書かれた分岐の続きから進める (次郎形式は上記)。
    BM/HBSCROLL の拍と BPM 表示は最初の分岐の BPM を使う

## Android 版

Android 版 (`Android/`) は PC 版と同じソースを NDK でビルドします。Android 専用の部分 (タッチ操作・入力ダイアログ・トースト) は
`#ifdef __ANDROID__` で分け、Windows 専用の機能 (Discord・録画・外部ツールの導入・Raw Input・MultiServer の起動) は Android では使いません。

- Android 版はリポジトリ内の共通 C++ ソースを直接参照します。
- 選曲画面では上下スワイプで移動し、ボックスをタップして選択します。選択中のボックスをもう一度タップすると決定します。タッチ太鼓は表示しません。
- 次郎形式・譜面制作・ギミック・新しいオンラインの通信 (サーバーとポートを指定、暗号化、曲の配布) も PC 版と同じです
- **SONGLINK のダウンロード**: [youtubedl-android](https://github.com/yausername/youtubedl-android) (yt-dlp・Python・ffmpeg を同梱。GPL-3.0) を使います。
  初回は準備と yt-dlp の更新に時間がかかります。背景動画 (MOVIELINK) は Android では再生しないので取得しません
- **zip のインポート**: ファイル管理アプリで zip を開く・共有する (複数可) と、`Documents/FAS/Songs` に解凍します。
  中身が 1 つのフォルダにまとまっていなければ zip の名前のフォルダに入れます。ファイル名が Shift_JIS の zip にも対応し、
  `../` などで Songs の外に書き込むエントリは書き込みません。アプリを開いている時でも受け付け、タイトルかモード選択の画面で譜面の一覧を作り直します

## スキン

### 演奏用の任意素材

- `Playing.Image.PlayerChar` は `Div` で区切ったコマを使います。`Playing.Config` の `PlayerCharFrames`、`PlayerCharGoGoFrames`、`PlayerCharClearFrames`、`PlayerCharMissFrames`、`PlayerCharJumpFrames` で状態別の表示順を指定します。通常周期は `PlayerCharLoopBeats`、ゴーゴー周期は `PlayerCharGoGoLoopBeats`、ジャンプの長さは `PlayerCharJumpBeats` です。マルチプレイ時は非表示です。
- `Playing.SE.ComboVoice` は `[{ "Combo": 50, "FilePath": "Sound/Voice/Combo_50.wav" }]` の形式で登録します。`FullComboVoice` にはフルコンボ時の音源を指定します。
- フルコンボ音源は、ダミーを除く判定対象の音符が連打・風船の終端まで通過してから、`Playing.Config.FullComboVoiceDelay` ms 待って再生します（標準 1000ms）。
- `Playing.SE.DonBig` と `KaBig` には大音符専用の効果音を指定できます。`Playing.Image.KeyMapBox` は Windows でのキー表示に使います。

## 背景動画

`BGMOVIE:` に動画ファイル、`MOVIEOFFSET:` に開始のずれ (秒) を指定します。
動画は譜面の時刻 (演奏開始 = 0) に同期し、一時停止・巻き戻し・再生速度の変更にも追従します。
